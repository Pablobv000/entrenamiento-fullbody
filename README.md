# Mini app de entrenamiento

## Estado
Proyecto actualizado y completo con los **5 días** siguiendo el **orden exacto de las capturas** (sin contar el calentamiento):
1. Lunes = tabla 1
2. Martes = tabla 2 (repetida de forma intencional)
3. Miércoles = tabla 3
4. Jueves = tabla 4
5. Viernes = tabla 5 (repetida de forma intencional)

## Qué incluye
- Calentamiento cargado en todos los días.
- 5 días completos.
- GIFs locales incrustados dentro de la propia página para cada ejercicio.
- Estructura PWA para abrirla en iPhone/iPad desde la pantalla de inicio.
- Soporte para GitHub Pages.

## Importante sobre los GIFs
Los GIFs se han generado como **demos visuales cortas y orientativas** para que puedas ver el patrón del movimiento directamente dentro de la app sin salir a YouTube.

## Cómo publicar gratis en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube el contenido de esta carpeta.
3. En GitHub entra en **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/root`.
6. Guarda y espera a que se publique.
7. Abre la URL en Safari desde iPhone o iPad y pulsa **Compartir > Añadir a pantalla de inicio**.
8. Marca **Abrir como app web**.

## Dónde editar
- `data.js` para ejercicios y estructura semanal.
- `assets/gifs/` para los GIFs.
- `styles.css` para el diseño.
